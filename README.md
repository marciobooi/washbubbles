# Washstore — Vite + React + Tailwind 4

This repository is now a Vite React app using Tailwind 4, created at the repository root (not inside a subfolder).

Quick start

1. Install dependencies:
   ```powershell
   npm install
   ```
2. Dev server:
   ```powershell
   npm run dev
   ```
3. Build:
   ```powershell
   npm run build
   ```
4. Preview production build:
   ```powershell
   npm run preview
   ```

Notes

- Tailwind content paths are configured in `tailwind.config.cjs`.
- Keep `washbubbles-repo` folder intact if you still want to keep older sub-projects.
